# 🎲 Monopoly Digital

Versão digital do clássico jogo **Monopoly**, desenvolvida em **C#**, com o objetivo de simular a dinâmica original do tabuleiro de forma interativa e intuitiva.  
O projeto foi desenvolvido em equipe como parte das atividades práticas da disciplina de **Gerência de Projetos de Software**, aplicando conceitos de **Scrum**, **EAP**, **Gráfico de Gantt**, **Burndown** e **Análise de Valor Agregado**.

---

## 🧠 Objetivo do Projeto
O objetivo do projeto é desenvolver uma versão digital do jogo **Monopoly**, aplicando metodologias ágeis e técnicas de gerenciamento de projetos de software.  
Durante o desenvolvimento, o time utilizou práticas como **planejamento de sprint**, **monitoramento de progresso** e **avaliação de desempenho** para acompanhar o andamento do projeto.

## 🧩 Metodologia

O desenvolvimento seguiu a metodologia **Scrum**, com sprints definidas e acompanhadas por meio de indicadores de desempenho.  
Os principais artefatos de acompanhamento foram:

- **EAP:** Definição das fases e tarefas do projeto.  
- **Gráfico de Gantt:** Planejamento temporal das entregas.  
- **Burndown Chart:** Monitoramento do progresso de cada sprint.  
- **Análise de Valor Agregado (EVA):** Avaliação de custo, prazo e desempenho.
